# Next Break - Data
Data for [Next Break](https://github.com/julian-jes/nextbreak) (Android app) and the [Next Break website](https://nextbreak.julianjesacher.org/).

Hosted via GitHub Pages, generated by a Python backend:

- **[data.json](https://julian-jes.github.io/nextbreak-data/data.json)**: The current school year's calendar, including school days and holiday start dates.
- **[version.json](https://julian-jes.github.io/nextbreak-data/version.json)**: The version of data.json, used to detect updates.
